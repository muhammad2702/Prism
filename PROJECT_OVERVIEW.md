# Project Overview

PRISM is a C++ and Python simulation project for configurable experiments. It shows systems programming, experiment design, reproducible configuration, and analysis workflows.

## Highlights

- C++ simulation engine
- Python configuration tooling
- XML configuration files
- CMake and Makefile build support
- Dockerfile for reproducible setup
- Multiple experiment configurations
- Output and analysis workflow

## Tech stack

C++, Python, CMake, Makefile, Docker, XML
