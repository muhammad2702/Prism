# PRISM: Agent-Based Simulation Platform

PRISM is a C++/Python simulation platform for running configurable agent-based experiments and analyzing emergent behavior in dynamic systems. The project is designed around reusable simulation code, XML experiment configuration, automated configuration generation, and reproducible experiment runs.

This repository is positioned as an engineering and research project: it demonstrates C++ system design, configuration-driven experimentation, Python automation, simulation modeling, and experiment documentation.
